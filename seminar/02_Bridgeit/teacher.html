03 「引き分けがない」の数学的根拠

ブリッジイットで引き分けが起きるとしたら、「盤面が全部埋まっても赤も青もゴールをつなげていない状態」です。これが絶対に起きないことを3つのステップで理解します。

ステップ1：盤面の構造（双対グラフ）

赤点格子と青点格子は「噛み合っている」

赤点の格子と青点の格子は、互い違いに配置されています。この結果、盤面上のすべての「交差点」において次のことが成り立ちます：

赤の縦橋が通るか、青の横橋が通るか、どちらか一方しか置けない（交差禁止ルール）

これにより赤グラフと青グラフは平面グラフの双対の関係にあります。一方の「橋なし」の空間が、もう一方の「橋を置ける場所」に対応しています。

ステップ2：壁と通路の二項対立

赤の「壁」は青の「通路」を分断する

赤が上から下へゴールをつなぐ経路を完成させた瞬間、その経路は盤面を左右に分断する壁になります。

平面において、左右を分断する壁が存在するとき、その壁をすり抜けて左右をつなぐ経路を作ることは位相幾何学的に不可能です。これはヨルダンの曲線定理の離散版として理解できます。

逆も同様です。青が左右をつなぐ経路を完成させたとき、その経路は赤の上下移動を遮断します。

ステップ3：Galeの定理

Gale の定理（1979年）

盤面の任意の完全配置（全スロットが赤か青で埋まった状態）において、赤が上下をつないでいるか、青が左右をつないでいるか、ちょうど一方が成立する。

証明のアイデア：
赤と青が双対グラフの関係にあることから、「赤が上下をつなぐ経路を持たない」という状況は論理的に「青の橋が赤の上下経路をすべて遮断している」ことと同値です。そしてそれは「青が左右をつなぐ経路を持つ」ことと同値になります。この論理的同値はMengerの定理（グラフ理論）の応用として厳密に証明されます。

授業での説明レベル：中学生には「赤の壁が完成したら、青はすり抜けられない」という直感的説明で十分です。N=3の小盤面で全パターンを書き出し、必ずどちらかが勝つことを確認させると体感的に納得できます。

04 必勝法：2段階で理解する
「必勝法がある」と「どこに置けばいいか」はまったく別の問題です。この2つを区別して理解することが、この単元の最大の数学的学びです。
第1段階：必勝法の「存在証明」― 戦略窃取論法

引き分けがないことが確認できれば、「先手か後手のどちらかに必ず必勝法がある」ことがわかります。では、どちらに必勝法があるのか。戦略窃取論法（Strategy-Stealing Argument）で証明します。

戦略窃取論法の手順

  1. 背理法の仮定：「後手（青）に必勝法 S が存在する」と仮定する
  2. 先手（赤）の行動：1手目は盤面の任意の場所に橋を1本置く。2手目以降は「自分が後手のつもりで」必勝法 S に従って行動する
  3. キーポイント：最初に置いた余分な橋は、自分にとって邪魔にならない（橋は増えるほど有利か中立。自分のゴールへの経路が増えることはあっても、減ることはない）
  4. 矛盾の発生：後手の必勝法 S で動いているはずの先手が負けるはずがない。これは「後手に必勝法がある」という仮定と矛盾する
  5. 結論：後手に必勝法は存在しない。引き分けもない。よって先手に必勝法が存在する
この証明が示すこと・示さないこと：
✅ 先手の必勝法が「存在する」こと
✅ 後手に必勝法はないこと
❌ 何手目にどこへ置けばよいかの具体的な手順
❌ 何手で勝てるか

「存在はわかるが中身はわからない」―― これが存在証明の特徴であり、数学の醍醐味のひとつです。
「必勝法があることは数学的に証明されています。でも、その具体的な手順は今もコンピュータの中にしかありません。答えがあることはわかっているのに、人間が直感的に理解できる形では書き下されていない。そういう問題が数学にはたくさん存在します。」
第2段階：具体的な必勝法「ペアリング戦略」

存在が証明されたので、次は「実際にどう指すか」です。それがペアリング戦略（Pairing Strategy）です。

ペアリング戦略の考え方

  • 盤面上の橋スロットをすべてペア（組）に割り当てる
  • 先手は1手目を盤面に置いた後、以降は「相手がペアの一方に置いたら、即座にもう一方に置く」を繰り返す
  • この戦略に従い続けると、相手がどこに置いても先手は上下のゴールをつなぐ道を必ず確保し続けられる
  • ペアの割り当ては盤面サイズによって異なるが、対称性を利用することで設計できる

直感的なたとえ：相手が「迂回路Aを塞いだら」、先手は即座に「迂回路Aの代わりになる迂回路B」を確保する。青がどこを遮断しようとしても、先手は常に代替ルートを手元に持っている状態を維持する。

N=3 の小盤面で試してみよう
生徒用HTMLの先頭にある const N = 6; を const N = 3; に変更すると3×3の小盤面になります。この盤面なら全手順を書き出せるので、ペアの割り当てを生徒自身が発見する体験学習に最適です。「特殊化から一般化」という数学的アプローチを体験させることができます。
05 数学における2種類の証明

このゲームを通じて、数学における証明には大きく2種類あることを教えることができます。これは中学生が初めて「証明とは何か」を深く考えるきっかけになります。

📌 存在証明（非構成的証明）

「○○が存在すること」を示す証明。具体的な中身は示さない。

  • 戦略窃取論法はこれにあたる
  • 「先手の必勝法が存在する」ことを背理法で示す
  • どこに置けばいいかは示さない
  • 「答えはある、でも何かはわからない」
🔨 構成的証明

「○○が存在すること」を、具体的に構成して示す証明。

  • ペアリング戦略はこれにあたる
  • 実際の手順を与えることで必勝法を示す
  • 「ここに置け」という具体的な指示がある
  • 「答えはある、そしてこれがその答えだ」

数学史上の有名な「存在証明」の例

  • 中間値の定理：f(a)＞0、f(b)＜0 なら f(c)=0 となる c が存在する（cがどこかは示さない）
  • 素数の無限性：素数が無限に存在することは証明できる（最大の素数がどれかは示せない）
  • 四色定理：4色で塗り分けられることは証明されているが、証明にコンピュータが必要で「美しい手証明」はない
「存在証明って不思議ですよね。答えがどこにあるかはわからないのに、『絶対にある』ことだけ証明できる。数学にはそういう場面がたくさんあります。ブリッジイットの先手必勝もそのひとつです。」

07 実施のヒントと教材カスタマイズ
シナリオ対応策
引き分けの理由が
伝わりにくい		 盤面を紙に印刷し、赤の橋を「壁」として塗りつぶしてみせる。壁が左右を分断すると青が通れないことが視覚的にわかる。または「川を渡る橋を赤が全部壊したら、青は反対岸に行けない」というたとえも有効。
先手有利の証明が
難しい		 「もし後手の必勝法があるなら、先手がその作戦を丸ごとパクれる。でもパクれたら先手が勝つ。矛盾！」と口語で説明する。黒板に「仮定→行動→矛盾→結論」の流れを書くと背理法の構造が見えやすい。
存在証明と構成的証明の
違いが伝わりにくい		 「宝箱の中に必ず答えが入っている（存在証明）。でも箱は開けられない。ペアリング戦略は箱を開けて見せるもの（構成的証明）」というたとえが有効。
奇数クラスで
ペアが余る		 3人グループで「観戦者が次の手を提案する」役を設けると全員が参加できる。または「引き分けを作ろうとする役」を設定し、作れないことを証人として確認させる。
早く終わった生徒 「N=3で先手必勝の具体的な全手順を書き出せ」という追加課題を与える。ペアの割り当てを自分で設計させるとさらに深い理解につながる。
